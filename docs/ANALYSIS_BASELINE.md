## 분석 과정에서 발견한 주의사항
- 원본 CSV는 헤더가 6개 필드인데 모든 데이터 행은 7개 필드(끝에 빈 값의 트레일링 콤마)를 갖고 있음. `header=0` 기본 옵션으로 그냥 읽으면 pandas가 첫 필드를 인덱스로 취급해 나머지 6개 열이 한 칸씩 밀리는 오류가 발생함(이번 분석에서는 `header=None` + 직접 열 이름 지정 + `skiprows=1`로 회피함).
- 파일은 UTF-8 BOM(`utf-8-sig`)으로 시작함.
- 상위 10개 역 집계는 "역명" 단위로 노선을 통합해 계산함(예: 환승역처럼 같은 역명이 여러 노선에 등록된 경우 합산됨). 노선별로 분리한 역 순위는 이번 분석에 포함하지 않음 — **미확인**.
- `등록일자` 열은 이번 분석 항목에 사용하지 않음 — 등록일자 자체의 결측치/이상치 여부는 **미확인**.
- 이 CSV는 2026년 8월 1개월치만 포함하므로, 다른 월 데이터와의 비교나 연간 통계는 **미확인**.
- 이번 분석은 원본 CSV 파싱 오류(트레일링 필드 등)를 코드로 수정하지 않고, 분석 스크립트 안에서만 우회 처리함 — `js/data.js`의 실제 파싱 로직이 이 기준값과 동일한 결과를 내는지는 이번 문서 작성 시점에서 별도로 재검증하지 않았으므로 **미확인**(이전 대화에서 `tests/analysis.test.js`의 대조 테스트가 통과한 사실은 있으나, 이 문서 자체는 그 테스트 결과를 기준값으로 삼지 않음).
