# 서울 지하철 대시보드 요구사항

- 원본 Notion 페이지: https://app.notion.com/p/3e81675ae56880e9926ffe62ce08ce3a?source=copy_link
- 확인 날짜: 2026-09-27

## 목적
서울시 실제 지하철 승하차 데이터를 사용해 이용 패턴을 브라우저에서 확인한다.

## 1. 필수 기능
1. 선택 범위의 총 승차 인원과 총 하차 인원
2. 승하차 합계 기준 이용객 상위 10개 역
3. 노선별 이용객 합계
4. 날짜별 전체 이용객 추이
5. 평일과 주말의 일평균 이용객 비교

## 2. 화면 요구사항
- 날짜 범위 필터
- 전체 또는 개별 노선 필터
- 총 승차, 총 하차, 총 이용량 KPI
- 상위 10개 역 막대차트
- 노선별 이용량 막대차트
- 날짜별 이용량 선차트
- 평일·주말 일평균 비교
- 필터링된 데이터 표
- 모바일 반응형 화면

## 3. 기술 조건
- HTML, CSS, 바닐라 JavaScript 사용
- React와 백엔드 서버는 사용하지 않음
- PapaParse로 CSV 처리
- Chart.js로 차트 구현
- 데이터 처리, 분석, 화면 코드를 분리
- 분석 함수는 DOM에 의존하지 않는 순수 함수로 작성
- 핵심 분석 함수의 단위 테스트 작성

## 4. 데이터 처리 규칙
- 원본 CSV 값을 임의로 변경하지 않음
- 실제 열 이름과 인코딩을 확인한 뒤 처리
- 날짜와 승하차 인원을 명시적으로 변환
- BOM, 열 이름 공백, 결측치 처리
- 화면과 README에 데이터 출처 표시

## 5. 완료 조건
- 단위 테스트 통과
- 실제 CSV 직접 계산과 분석 함수 결과 일치
- 브라우저 콘솔 오류 없음
- 날짜와 노선 필터 정상 작동
- git diff 확인 전 commit 및 push 금지

## 6. 확인이 필요한 모호한 내용
- "평일·주말 일평균 비교"의 화면 형태(차트/카드/표 등)가 명시되어 있지 않음
- "원본 값을 임의로 변경하지 않음"과 "결측치 처리" 규칙이 동시에 존재하나, 결측치를 구체적으로 어떻게 처리할지(제거/대체/표시)는 명시되어 있지 않음
- 데이터 파일이 여러 달치일 경우 병합 방법에 대한 명시가 없음(Notion 문서에 언급 없음)
- "백엔드 서버 사용 금지"가 정적 파일 서빙까지 포함하는지 명시되어 있지 않음
- 단위 테스트의 실행 환경(프레임워크, 실행 방법)이 명시되어 있지 않음
